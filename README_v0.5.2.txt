THAN Quiz Assistant v0.5.2 — Large Center Answer Display

What's new:
- Verified answers open in a separate, centered, always-on-top window.
- Large text displays the actual answer content and on-screen choice position.
- Works with multiple verified answers and shuffled choice order.
- Previous answer closes when reading a new question; Escape closes the popup.
- Manual button: 'Hiện đáp án lớn giữa màn hình' to reopen the current verified answer.
- Unverified questions never display an answer as verified.

Install: close the old application, extract ZIP, run SETUP_ONE_CLICK.bat.
Your question bank is stored under %APPDATA%\ThanQuizAssistant and is not replaced by this installer.

Verification: Python syntax and existing 5 matching tests passed. Windows GUI has not been tested in this environment.
