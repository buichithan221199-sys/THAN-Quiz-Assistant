THAN Quiz Assistant 1.0 — Chi Than Bui

Branding update based on working v0.6.6. Includes app icon, logo and developer signature.

WINDOWS BUILD:
1. Install Python 3.12 and ensure Python is available on PATH.
2. Run BUILD_WINDOWS.bat (Internet required to install packages).
3. EXE is created in dist\THAN Quiz Assistant.exe.
4. Tesseract OCR and Vietnamese language data must still be installed separately on Windows.

IMPORTANT: This archive is source plus a Windows build script, not a precompiled EXE or signed installer. Windows SmartScreen may warn on unsigned builds. OCR and Always On Top have not been tested on Windows here.
